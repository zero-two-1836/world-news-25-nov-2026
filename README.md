# The World Today — Wednesday, 25 November 2026

A newspaper front page summing up the world's news of Wednesday, 25 November 2026:
ten stories from six continents, each cross-checked against at least two
independent sources. Hero story: the Houthi strike on Riyadh's PIF Tower.

`main.py` (stdlib only) copies the shipped `entry.png` to `/output/entry.png`;
`build_image.py` draws the page with Pillow. Run `python3 build_image.py`
to regenerate the image deterministically.
